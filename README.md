# Сборщик Shiki Material 3
Конфигурация веб-сборщика для обновлённой темы Shiki Material 3. Интерфейс работает на [Vue.js](https://github.com/vuejs/vue), а готовый код подключает опубликованные CSS-файлы темы.

Сборщик полностью работает при открытии `index.html` через `file://`: JSON-конфигурация встраивается в `src/js/theme-config.js`, а готовый CSS темы — в `src/js/theme-bundle.js`. Копируемый результат содержит саму тему и не зависит от внешнего хостинга; отдельная копия CSS хранится в `theme/main.css`. Сборщик сохраняет совместимые переменные `--color-*` и дополнительно генерирует актуальные цветовые роли `--md-sys-color-*`: основные, вторичные и третичные контейнеры, поверхности, контуры, инверсные и error-роли. Тональные значения автоматически учитывают светлую или тёмную схему.

Светлая палитра синхронизирована со сборкой `master` версии 3.0.0: основной цвет `#65558f`, вторичный `#625b71`, фон `#fffbfe`, отдельные цвета ссылок и верхнего меню.

### Файлы темы
Исходные файлы темы хранятся в папке [`/assets`](https://github.com/abelban/shiki-material3/tree/master/assets/), а их список — в [`theme_files.json`](https://github.com/abelban/shiki-material3/blob/master/config/theme_files.json). Каждая ветка может иметь собственный набор файлов и конфигурацию.


### Настройки сборщика
Списки палитр, цветовых настроек, вычислительных помощников и подключаемых файлов находятся в папке [`/config`](config/). Целевая ветка и версия темы, а также путь к CSS вынесены в `config/theme_sources.json`. Пользовательские настройки сохраняются в `localStorage` браузера.

После изменения JSON пересоберите автономный конфиг:

```sh
node scripts/build-config.js
```

Чтобы синхронизировать CSS с новой минифицированной сборкой `master` и безопасно удалить персональный ID, фон и тестовый режим полноэкранной обложки:

```sh
node scripts/sync-master-theme.js /path/to/master/dist/theme.min.css
```
