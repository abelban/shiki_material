# Shiki Material 3 для [Shikimori](https://shikimori.io)
Современная тема по мотивам актуальной системы [Material Design 3](https://m3.material.io/). В теме используются цветовые роли, типографика, формы, состояния, анимации, высоты поверхностей и Material Symbols Rounded из Material 3. Размеры интерактивных элементов рассчитаны на управление мышью и сенсорным экраном.

Тема рассчитана на современные версии Chrome, Firefox, Safari и Edge. Так как разметка Shikimori регулярно меняется, рекомендуется следить за [обновлениями темы](https://github.com/abelban/shiki-material3/commits/master).

## Совместимость с CSS Shikimori

Исходники учитывают [особенности пользовательских стилей Shikimori](https://shikimori.io/clubs/811-css-club-nastroyka-vneshnego-vida-sayta/pages/1774-osobennosti-css-na-shikimori): итоговый стиль содержит собственный media-запрос, не использует `@charset` и не содержит запрещённую латинскую подстроку в CSS. При самостоятельной компиляции передавайте Sass флаг `--no-charset`. После публикации импортируемого файла необходимо сбросить кеш на странице `/tests/reset_styles_cache`.

## Установка
Удобнее всего воспользоваться специальным [сайтом-сборщиком](https://grin3671.github.io/shiki-theme/), где можно настроить цвета, обложку и фон по своему вкусу. Нажмите «Создать тему», и после завершения сборки скопируйте готовый код в настройки внешнего вида сайта.

Важно! Чтобы узнать свой ID, скачайте свою аватарку: цифры в названии файла – это ваш ID.

Все свои настройки указывайте в конце стиля в разделе "Мои настройки":
```css
/* МОИ НАСТРОЙКИ */

/* Фон меню */
.l-top_menu:before {
  background-color: #212121;
}
```

Если по каким-то причинам использовать сборщик не представляется возможным, используйте [готовые релизы темы](https://github.com/grin3671/shiki-theme/releases): найдите наиболее новую версию, скачайте одну из представленных тем, а затем скопируйте код себе в настройки.

#### Установка обложки
Для того чтобы обложка отображалась в вашем профиле, вам потребуется заменить все вхождения `2727` на ваш ID. Используйте для этого поиск по странице (сочетание клавиш `Ctrl+F`). Чтобы узнать свой ID, скачайте свою аватарку: цифры в названии файла – это ваш ID. Ссылка на изображение указывается в самом конце файла:
```css
/* Моя обложка в профиле */
.p-profiles .profile-head[data-user-id = "2727"] .c-brief:before {
  /* background-image: url(//i.imgur.com/bd8W6VB.jpg); /* Пример */
  background-image: url(); /* Моя обложка */
  background-position: center;
}
```


## Превью
### Локальная сборка

Установите Node.js (22 LTS или новее), затем выполните:

```sh
npm ci
npm run build
npm run check
```

Сборка использует отмеченные файлы из `config/theme_files.json` и параметры
`config/build.sass`, включая цвета, ID профиля и обложку. Обновляются обе версии
CSS в `dist`. Команда `check` проверяет компиляцию, ограничения CSS Shikimori
и соответствие готовых файлов исходникам.
