# Сборщик Shiki Material 3
Конфигурация веб-сборщика для обновлённой темы Shiki Material 3. Интерфейс работает на [Vue.js](https://github.com/vuejs/vue), а готовый код подключает опубликованные CSS-файлы темы.

Сборщик сохраняет совместимые переменные `--color-*` и дополнительно генерирует актуальные цветовые роли `--md-sys-color-*`: основные, вторичные и третичные контейнеры, поверхности, контуры, инверсные и error-роли. Тональные значения автоматически учитывают светлую или тёмную схему.

### Файлы темы
Исходные файлы темы хранятся в папке [`/assets`](https://github.com/abelban/shiki-material3/tree/master/assets/), а их список — в [`theme_files.json`](https://github.com/abelban/shiki-material3/blob/master/config/theme_files.json). Каждая ветка может иметь собственный набор файлов и конфигурацию.


### Настройки сборщика
Списки палитр, цветовых настроек, вычислительных помощников и подключаемых файлов находятся в папке [`/config`](config/). Адреса опубликованных CSS-файлов вынесены в `config/theme_sources.json`, поэтому тестовую или стабильную сборку можно переключить без правки JavaScript. Пользовательские настройки сохраняются в `localStorage` браузера.
